# 游戏内NPC对话生成与上下文管理系统

## 项目描述

游戏内NPC对话生成与上下文管理系统的bug修复项目。核心模块 `ai/dialogue.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 回复生成完全没做对话都是固定的
- 上下文管理完全没做只记得上一句话
- 回复策略完全没做不知道该怎么回复
- 个性化完全没做所有NPC说话都一样
- 对话状态完全没做不知道对话进行到哪里

## 运行测试

```bash
python -m pytest tests/test_dialogue_generator.py -q
```

修复目标：所有 14 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
